# Re-buntu fetch logo

Re-buntu provides a terminal-friendly logo intended for use by **any fetch application** that supports custom ASCII/Unicode logos.

The canonical logo is stored at:

```text
/usr/share/re-buntu/fetch/logo.txt
```

Compatible fetch applications can use or copy this logo, including tools such as:

- Fastfetch
- Neofetch
- Screenfetch
- Other fetch utilities with custom-logo support

The repository does not assume a single fetch application. Integrations should use the canonical logo asset so the Re-buntu branding stays consistent.
