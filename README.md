# Re-buntu

**Re-buntu** is a RebuiltTux distribution based on Ubuntu.

## About

Re-buntu is part of the RebuiltTux project family and aims to provide a customized Ubuntu-based Linux experience with RebuiltTux branding, tooling, and configuration.

## Project goals

- Build a bootable Ubuntu-based RebuiltTux distribution
- Add RebuiltTux customization and branding
- Provide a reproducible build process
- Keep the project easy to modify and rebuild

## Status

🚧 Early development — the build system is being created.

## Name

The distribution is named **Re-buntu**, reflecting its Ubuntu base and its place in the RebuiltTux project family.
